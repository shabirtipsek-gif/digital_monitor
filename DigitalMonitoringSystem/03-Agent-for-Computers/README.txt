Monitoring agent for the Digital Monitoring System (Mukono District Local Government)
Nothing to install.
1. On the dashboard: Enroll a device > Download appsettings.json
2. Replace appsettings.json in this folder with the downloaded file.
3. Double-click RUN-AGENT.bat  (the computer appears ONLINE on the dashboard)
4. Optional: right-click INSTALL-AUTOSTART.bat > Run as administrator, so it starts at every boot.
